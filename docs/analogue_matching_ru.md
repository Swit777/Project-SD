# Подбор аналогов: версия 3

## Что изменилось

Поиск вынесен в отдельный каталог 94 016 платных выпущенных игр из закреплённого снимка Steam.
Исследовательский корпус из 8 000 игр, обученная модель и её контрольные метрики не заменены.
Наличие owner-метки для каталога не обязательно; неизвестные значения остаются неизвестными.

Доступны три режима:

| Режим | Минимум отзывов | Доля выбранных механик | Цена | Выбранные Co-op/PvP | Порядок |
| --- | --- | --- | --- | --- | --- |
| Ближайшие | 30 | 50% | Без жёсткого ограничения | Категории Steam | Сходство |
| Рыночные референсы | 100 | 25% | Без ограничения | Не обязательны | Число отзывов |
| Строгий | 30 | 100% | От 1/3 до 3 цен концепции | Категории Steam | Сходство |

Пороги можно менять. В широком режиме игра с другим сетевым режимом может быть референсом,
но это отличие показывается явно. Отзывы характеризуют публичный отклик, а не подтверждённый
коммерческий успех. Рейтинг по отзывам не является рейтингом сходства.

## Игра-Ориентир

В разделе «Формат игры и ориентир» можно найти существующую игру по названию или AppID.
Сходство уточняется по её тегам Steam; сама игра исключается из выдачи. Дополнительно доступны
теги 2D/3D, вид камеры, поджанры и формат. Их обязательность включается отдельным флажком.

Например, для Indie/RPG с крафтом и кооперативом ориентир Stardew Valley выводит в начало
Coral Island, Roots of Pacha, Sun Haven и Dinkum. Это пример фактической выдачи в текущем снимке,
не независимая оценка качества рекомендаций. Без ориентира такая концепция остаётся очень широкой.

## Как Рассчитывается Сходство

Для выбранных механик: `S = 0.55 * (0.7 * coverage + 0.3 * Jaccard) + 0.25 * genre + 0.12 * price + 0.08 * age`.
Без выбранных механик: `S = 0.8 * genre + 0.12 * price + 0.08 * age`.
Indie имеет вес 0.1 в жанровом Жаккаре; другие жанры имеют вес 1. Одного Indie недостаточно,
если в концепции задан содержательный жанр. Цена и возраст сравниваются в логарифмической шкале.

При наличии тегового запроса: `score = 100 * (0.45 * S + 0.55 * cosine(TFIDF))`.
TF–IDF обучается на тегах каталога без целевых меток, общие жанры исключены из токенов.
При неизвестных тегах применяется только структурное сходство, с предупреждением.
Веса эвристические; они не подбирались по экспертной разметке. Число отзывов и owner-диапазоны
не входят в балл сходства. Идентификатор служит лишь для устойчивого разрешения одинаковых баллов.

## Достоверность Данных

- «0–20 тыс.» — нижняя грубая категория SteamSpy, не 20 000 продаж. Точное значение неизвестно.
- Отсутствующий счётчик отзывов не превращается в ноль; ноль снимка не гарантирует ноль отзывов сегодня.
- Co-op/PvP в обязательном режиме подтверждаются категориями, не только описанием персонажей.
- Кнопка «Обновить отзывы Steam» получает отдельную сводку API с датой, параметрами и SHA-256 ответа.
- Свежая сводка не заменяет старые метки и не участвует в обучении или сортировке исторического каталога.
- Фильтр отзывов смещает состав аналогов к заметным играм; частоту успеха по этому списку оценивать нельзя.
- Теги, формат и ориентир влияют только на поиск, не на прогноз вероятностей текущей модели.

Источники: [ограничения SteamSpy](https://steamspy.com/about),
[публичные сводки Valve](https://partner.steamgames.com/doc/webapi/IUserReviewsService),
[TF–IDF в scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html).

## Воспроизведение

```powershell
python run_game_concept.py analogues-catalog
python scripts/verify_analogue_upgrade.py
python -m unittest discover -s tests -v
```

Первый шаг заново строит каталог, не переобучая ML-модель. Для существующего каталога версии 2
есть быстрый переход к тегам: `python run_game_concept.py analogues-tags`.

Отчёт: `reports/game_concept/analogue_upgrade/comparison.json`; примеры: `examples.csv`,
`anchor_stardew.csv`. Сравниваются пять фиксированных запросов, глубина 12, реконструированное
старое ранжирование и новые режимы. Число кандидатов и соблюдение фильтров не заменяют Precision@k/NDCG.
Для этих метрик необходима независимая экспертная оценка пар «концепция — игра».

Проверка интерфейса: `python scripts/verify_analogue_ui.py --url http://127.0.0.1:8502`.
Используются локальные Selenium и Chrome, результаты сохраняются отдельно от прежних иллюстраций статьи.
