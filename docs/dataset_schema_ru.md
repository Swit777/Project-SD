# Схема датасета

Каждая строка описывает запуск одного AI-агента на одном сгенерированном уровне.

## Идентификаторы

| Колонка | Значение |
|---|---|
| `level_id` | устойчивый идентификатор уровня |
| `seed` | seed генерации уровня |

## Признаки уровня

| Колонка | Значение |
|---|---|
| `size` | размер grid-world карты |
| `requested_obstacle_density` | заданная плотность препятствий |
| `actual_obstacle_density` | фактическая плотность препятствий |
| `open_cell_ratio` | доля свободных клеток |
| `wall_count` | число препятствий |
| `has_path` | существует ли путь от старта к цели |
| `shortest_path_length` | длина кратчайшего пути |
| `shortest_path_norm` | нормализованная длина пути |
| `manhattan_distance` | Manhattan distance от старта до цели |
| `directness` | насколько путь близок к прямому маршруту |
| `accessible_area_ratio` | доля достижимой свободной области |
| `dead_end_ratio` | доля тупиков |
| `branch_cell_ratio` | доля клеток-развилок |
| `mean_degree` | среднее число соседей у свободных клеток |
| `start_degree` | число ходов из стартовой клетки |
| `goal_degree` | число ходов около цели |
| `max_steps` | лимит шагов для прохождения |

## Результаты агента

| Колонка | Значение |
|---|---|
| `agent` | имя агента |
| `success` | 1, если агент прошел уровень, иначе 0 |
| `success_rate` | доля успешных прохождений |
| `steps` | среднее число шагов |
| `reward` | средняя награда |
| `episodes` | число запусков агента |
| `difficulty` | сложность уровня для агента: `1 - success_rate` |

## Требование к новому CSV

Для обучения новый датасет должен иметь все перечисленные колонки. Тогда приложение сможет проверить структуру, обучить модели и построить отчеты без ручной переделки кода.

Для предсказания достаточно входных колонок без результатов агента:

```text
level_id, seed, признаки уровня, agent
```

В этом случае приложение использует сохраненную модель `reports/best_model.pkl` и рассчитывает:

- `predicted_success_probability`;
- `predicted_success`;
- `predicted_difficulty`.

Пример такого файла:

```text
data/processed/sample_new_levels.csv
```
