# Исследовательский Протокол

## Цель

Проверить, содержит ли недавняя динамика завершения игровых подзадач дополнительную
информацию о текущем субъективном удовольствии по сравнению с контекстом и общей активностью.
Тема развивает диплом об анализе поведения игрока без разработки новой игры.

## Четыре Задачи

1. Получить лицензированный публичный набор, определить цель и проверить качество/пригодность телеметрии.
2. Построить воспроизводимые признаки по прошлому поведению без утечек между игроками и эпизодами.
3. Сравнить модели и парно проверить гипотезу с оценкой неопределённости.
4. Сформировать результаты, ограничения и приложение для повторения анализа на совместимых данных.

## Основное Сравнение

Random Forest aggregate против Random Forest dynamic. Архитектура, число деревьев,
ограничения глубины/листа, seed, train-игроки и test-игроки одинаковы. Отличается набор признаков.
Random Forest выполняется одним worker, чтобы порядок суммирования прогнозов деревьев был детерминированным.
Модель dynamic добавляет прошлые окна и два показателя недавней активности.
Контроль: контекст уровня, режима, оборудования, прогресса и агрегированная активность эпизода.
Дополнительные модели: константа-среднее, константа-медиана, Ridge, Bayesian Ridge.
Медианная константа важна, поскольку основная метрика — абсолютная ошибка.

Доли игроков: приблизительно 60% train, 20% validation, 20% test; округление задаёт GroupShuffleSplit.
Игроки не пересекаются. Внутренние обработки категорий, масштабирования и пропусков обучаются на train.
Каждый игрок в обучении имеет одинаковый суммарный вес независимо от количества ответов.
Модель для приложения выбирается по validation MAE, усреднённой сначала внутри игрока, затем между игроками.
Она не дообучается на test. GroupKFold проводится на development (train + validation).

## Проверка Гипотезы

Для каждого test-игрока рассчитывается средняя абсолютная ошибка каждой из двух RF-моделей.
Из этих пар получают разность: aggregate MAE минус dynamic MAE.
Bootstrap с возвращением выбирает **игроков**, сохраняя парность двух ошибок; 2000 повторов,
95% percentile-интервал. Это учитывает повторные ответы внутри игрока, но не неопределённость
всей процедуры обучения на разных train-выборках.

- Весь интервал выше нуля: свидетельство в пользу динамики в данном эксперименте.
- Весь интервал ниже нуля: динамика хуже в данном эксперименте.
- Интервал включает ноль: убедительных свидетельств преимущества нет; это не доказательство равенства.

R², RMSE и обычная MAE по строкам дополнительно раскрывают качество. Отрицательный R² означает,
что на этой test-выборке результат хуже её постоянного среднего по квадратной ошибке.
Нельзя сравнивать только разные алгоритмы и приписывать разницу временному окну.

## Дополнительный Анализ

Отдельные временные окна и permutation importance — разведочные результаты.
Они не используются для изменения основной гипотезы после просмотра test.
Важность считается для RF dynamic по обычной MAE строк и может расходиться с player-balanced метрикой.
Корреляция входов и случайность перестановок ограничивают интерпретацию; причинных выводов нет.

Дескриптивные интервалы выбранной модели: 90-й процентиль абсолютной ошибки на validation;
симметричный радиус, границы обрезаются шкалой 0–100. Test служит оценкой покрытия,
а не калибровкой. Из-за зависимых ответов, выбора модели на validation и нового домена гарантии покрытия нет.
Это не строгий байесовский credible interval и не вероятность эмоции.

## Практическая Ценность И Границы

Если поведение предсказывает опыт, это аргумент за дальнейшие исследования адаптивных систем.
Если нет, это ограничивает возможность использовать эту телеметрию как самостоятельный сигнал
и указывает на необходимость иных признаков, персональных моделей или дополнительной обратной связи.
Текущая работа не выбирает автоматически изменения игры и не проверяет, улучшат ли они опыт.

Одна игра и добровольная исследовательская версия ограничивают переносимость. Высокая доля исключённых
ответов требует явного аудита. Односекундная точность не позволяет восстановить порядок одновременных
событий. Длинные эпизоды могут включать паузы и неполную телеметрию.
Повторный запуск с новым CSV воспроизводит вычисления, а не обещает неизменность чисел.

Собственный вклад — исследовательский дизайн, реконструкция эпизодов, извлечение временных признаков,
контроль утечек и статистическая проверка. Заявление о глобальной научной новизне требует отдельного
обзора связанных работ. Этот документ — рабочий протокол, не пререгистрация исследования.
