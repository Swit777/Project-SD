# Game Concept Lab

Исследовательское приложение: **как жанр и сочетание игровых элементов связаны с масштабом аудитории и игровыми часами**.
Конструктор сравнивает концепции с существующими играми Steam. Он не обещает продажи, прибыль или удержание,
которые нельзя достоверно восстановить из публичных страниц.

## Запуск

Проверенная среда: Python 3.14.2, Windows. В текущей папке данные и модель уже подготовлены.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

Полный воспроизводимый эксперимент:

```powershell
python run_game_concept.py run-all
python -m unittest discover -s tests -v
```

Первый запуск скачивает закреплённый CSV размером около 401 MB. Повторный запуск проверяет SHA-256,
а прямой парсер использует локальный проверяемый кеш. Настройки: `configs/game_concept.json`.
Конфигурация передаётся до команды: `python run_game_concept.py --config configs/game_concept.json train`.

## Данные И Парсер

Подготовлены **8 000 игр**, **18 846 свидетельств игровых элементов** и **11 359 текстовых кандидатов особенных возможностей**.
Из 125 855 строк источника фильтры прошли 89 170; выбрана воспроизводимая подвыборка по хешу AppID+seed,
а не только известные успешные игры. Игровые часы доступны у 2 021 игры: остальные значения не превращаются в нули.

Основной корпус: [Steam Games Dataset автора FronkonGames](https://huggingface.co/datasets/FronkonGames/steam-games-dataset),
закреплённая ревизия `ba4e26785af33bee500e96597068c6e77f4edea9`, CSV версии 20.06.2026.
Это готовый снимок Steam/SteamSpy, а не 8 000 страниц, заново скачанных нашим парсером.
Отдельно наш прямой парсер успешно обработал **36 игр Steam**, включая Stardew Valley, Terraria и Hades.
Свежие описания не соединяются автоматически со старыми целевыми метками.
У 7 из 36 игр HTML-страница недоступна/закрыта: сохранены публичные API-метаданные, теги страницы неизвестны.

```powershell
python run_game_concept.py download
python run_game_concept.py prepare
python run_game_concept.py scrape
python run_game_concept.py scrape --appids 413150 105600 1145360
python run_game_concept.py scrape --appids 413150 --refresh
python run_game_concept.py train
```

Парсер извлекает метаданные, цену, жанры, категории, пользовательские теги, описание, игровые элементы,
кандидаты уникальных возможностей и агрегаты небольшой выборки отзывов. Ограниченный пакет: до 1 000 AppID;
пауза между сетевыми запросами не меньше 1.5 секунды. Блокировки и возрастные формы не обходятся.
Обновления добавляют/обновляют отдельные игры, не удаляя остальной собранный корпус.

Каталог содержит **36 элементов**: крафт, строительство базы, кооператив, перманентная смерть,
ветвящийся сюжет, автоматизация, взаимодействие с физикой и другие. Для признака сохраняются URL,
тип свидетельства, фраза и отрицание. Это проверяемые заявления, не измерение качества реализации.
Текстовые кандидаты не входят в модель до ручной разметки. Precision/recall извлечения пока не измерены независимо.

## Приложение

- Концепция: параметры продукта, вероятности диапазонов аудитории, часы с интервалом, сравнение с частотами train.
- Отдельный каталог 94 016 игр: ближайшие аналоги, заметные рыночные референсы и строгий поиск; при необходимости только train.
- Игра-ориентир, TF–IDF-сходство тегов, фильтры отзывов и механик, объяснение различий, обновление сводки отзывов Steam.
- Графики цены и отзывов, профиль сходства и матрица механик; матрица ошибок ML, распределения корпуса, графики компонентов и LIME.
- Сравнение компонентов при фиксированном контексте, локальное объяснение LIME.
- Согласованность изменения компонентов по Logistic / аддитивной HGB / HGB со взаимодействиями; CSV сравнения.
- Корпус, поиск игр, свидетельства механик, прямое извлечение отдельной страницы Steam.
- Ручной аудит: описание и разметка рядом, сохранение экспертных меток, импорт/экспорт и precision/recall по рассмотренным утверждениям.
- Сравнение моделей и проверка гипотезы; загрузка другого совместимого CSV для прогноза или обучения.

Рабочий интерфейс ориентирован на компьютер; отдельная мобильная версия не разрабатывается.

Подбор аналогов и прогностическая модель разделены: теги ориентира и фильтр отзывов не меняют
предсказания. Референсы с большим числом отзывов не выдаются за прямые аналоги или доказанно прибыльные игры.
Нижний owner-диапазон SteamSpy не означает 20 000 продаж. [Подробности нового поиска](docs/analogue_matching_ru.md).

Большое число популярных механик не превращается в гарантированный успех. Модель обучена на реальных сочетаниях;
редкие пары, связи жанр–элемент, чрезмерная плотность и выход за поддерживаемые цены/возраст приводят к предупреждению
или отказу от численного прогноза. Эти правила не являются произвольным штрафом качеству необычной игры.

## Исследование

**Гипотеза:** учёт взаимодействий механик улучшает прогноз по сравнению с теми же признаками без взаимодействий.
Основная пара — одинаковые HGB-классификаторы с `no_interactions` и без этого ограничения.
Дополнительно сравниваются prior, жанры/контекст, Logistic Regression; для часов — медиана, Bayesian Ridge и HGB.
Игры общих разработчиков группируются транзитивно. Train / validation / calibration / test не пересекаются по этим группам.
Отдельная калибровка вероятностей, парный bootstrap по разработчикам, временной backtest, permutation importance и LIME.
Добавлены test-графики до/после калибровки, фиксированные 10-bin ECE и binary Brier для границ 20k/100k/500k.
Калибровка не автоматически лучше: в текущем наборе ECE границы 20k вырос с 0.0159 до 0.0271.
Такая диагностика не используется для подбора варианта по test.

## Ручной Аудит

Подготовлены 40 случайно отобранных игр и 1 440 задач: все 36 элементов каждой игры, а не только найденные положительные примеры.
Меткам доступны `1` (подтверждается метаданными), `0` (не подтверждается), `unclear` и пустое значение.
Пропуски не считаются отрицательными; метрики выводятся только по рассмотренным задачам с указанием покрытия.
Разметка ещё не выполнена, поэтому реальных precision/recall извлечения пока нет.

```powershell
python run_game_concept.py audit-create --games 40
python run_game_concept.py audit-evaluate --input path/to/mechanic_reviews.csv
```

Экспертный CSV связывается с конкретными задачами и версией корпуса. Чужие ID, дубли и невалидные метки отклоняются.
Повторное создание того же аудита не затирает ответы; новая версия корпуса сохраняется отдельно.
Метки не подмешиваются автоматически в обучение. Проверяется наличие заявлений в метаданных, не качество механик в самой игре.
Схема и порядок проверки: [аудит](docs/game_concept_annotation_ru.md).

В первом эксперименте по validation выбрана **аддитивная HGB**, а преимущество взаимодействий **не подтверждено**.
Test group log loss: prior 0.7104, жанры/контекст 0.6159, аддитивная HGB 0.5954, HGB со взаимодействиями 0.5989.
Числа не доказывают причинное влияние компонентов. Актуальные результаты пересчитываются в
[отчёте](reports/game_concept/research_report_ru.md).

Собственный вклад — постановка вопроса, извлечение элементов с доказательствами, воспроизводимая выборка,
контроль утечек, сопоставимый эксперимент, оценка неопределённости и проверка поддержки концепции.
Это не новый алгоритм ML с нуля и не заявление о мировой новизне.

## Другой Набор

Поддерживается та же схема и смысл признаков, не произвольный CSV. Для прогноза метки не нужны.
Для нового эксперимента нужны ещё диапазоны владельцев, часы, AppID, даты и разработчики;
минимум 100 игр и 20 независимых групп, все четыре класса в train/validation/calibration.
Приложение сохраняет отдельные результаты в `reports/game_concept/uploads/`.

```powershell
python run_game_concept.py train --input path/to/prepared.csv --output reports/my_experiment
```

Перенос на новый набор воспроизводит методику, а не гарантирует те же числа или качество.
[Схема CSV](docs/game_concept_schema_ru.md), [протокол](docs/game_concept_protocol_ru.md),
[источники и права](docs/steam_sources_ru.md), [краткое описание работы](docs/game_concept_brief_ru.md).

## Ограничения

Диапазоны SteamSpy — **оценки владельцев, не проданные копии**. Игровые часы — **не D7/D30-retention**.
Без транзакций, рекламных расходов и качества исполнения нельзя достоверно прогнозировать прибыль.
Теги, описания и цена снимка могли изменяться после релиза: это ретроспективный прототип на аналогах,
а не валидированный прогноз будущих годовых продаж. Возраст аналогов не является кривой продаж.

Карточка набора объявляет MIT для компиляции; это не передача прав на описания и обложки.
Исходные HTTP-ответы могут содержать публичные идентификаторы авторов отзывов; наружу экспортируются агрегаты.
Raw, кеш, тексты подготовленного корпуса, загруженные CSV и бинарные модели исключены из Git.
В GitHub публикуются код, инструкция воспроизведения и агрегированные результаты. Репозиторий пока не создан/не опубликован.

Предыдущие проекты не удалены: `player_experience_app.py` и `legacy_game_app.py`;
старый CLI `run_pipeline.py` относится к PowerWash, новый — `run_game_concept.py`.
Исследовательский отчёт автоматически сформирован; итоговые слайды ещё требуют подготовки.

DOCX использует оформление предоставленного файла `Статья_цены_подержанных_автомобилей_.docx`:

Она проверена открытием и экспортом в Microsoft Word. Поля автора, e-mail, группы и руководителя пока не заполнены.

`analogue_upgrade/tests.log` и изображения desktop-проверки. Она не меняет исходные результаты ML-эксперимента.
